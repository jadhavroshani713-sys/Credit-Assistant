# CREDIT ASSISTANT — Frontend

The modern React Single Page Application (SPA) for Credit Assistant, built with Vite, React Router v7, and Recharts.

## Tech Stack
- **React 19**
- **Vite 8**
- **React Router 7**
- **Recharts 3**

## Available Scripts

In the `frontend` directory, you can run:

```bash
# Start Vite development server
npm run dev

# Run Oxlint for code quality
npm run lint

# Build production bundle
npm run build

# Preview production build locally
npm run preview
```

## Environment Configuration

Configure `frontend/.env`:
```env
VITE_API_URL=http://localhost:8000
```
